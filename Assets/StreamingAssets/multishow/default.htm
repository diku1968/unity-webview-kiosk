 Update v3.0: November 1, 2001
  1. Applet is now rename Multi-Pic Slide Show as it's final version.
  2. New Option: Now you can make the images move diagonally
  3. New Option: New Text-Type #3 where the whole image becomes a hyperlink instead of a tiny enter button
  4. New Option: Now you can set the Max Speed the images can move at from 1-8
  5. Now the Images will stream so you don't have to wait for all the images to be loaded for the applet to start.
 Update v2.0: November 1, 2000
Probably the last update for Image Show.
  1. New Option: Add a link to each picture.
  2. New Option: Add a background image use 3 methods (center, tile, scale)
  3. New Interaction: Ablity to stop a image by moving the mouse over it.
  4. New Interaction: Ablity to drag an image around.
  5. New param method for adding pictures, text, and links.
  6. Timer to slow down images that go too quickly on fast computers.
 Update v1.2: June 11, 1999
  1. Reloading Bugs Corrected.
  2. New Options: Add text desciptions to each picture.
